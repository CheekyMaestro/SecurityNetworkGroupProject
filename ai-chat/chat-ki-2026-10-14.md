Yang **tidak** cocok untuk kita:

- RC4 di sana tidak memakai nonce. Kita pakai `HMAC-SHA256(rc4_key, nonce)` supaya kunci RC4 tidak pernah dipakai dua kali.
- Format envelope JSON base64 dan CLI-nya tidak relevan, karena kita menyimpan ke SQLite dan file `.bin`.

## Apa itu PR?

**PR (Pull Request)** adalah permintaan di GitHub untuk menggabungkan satu branch ke branch lain, misalnya `be` ke `main`. Bedanya dengan push langsung:

- Perubahannya ditampilkan di GitHub dulu: file mana yang berubah dan baris mana yang ditambah atau dihapus.
- Anggota tim bisa membaca, memberi komentar, atau minta perubahan sebelum digabung.
- Setelah oke, cukup klik **Merge**, dan isi `be` masuk ke `main`.

Jadi PR itu semacam "minta izin tim sebelum menggabungkan". Untuk tim kecil sifatnya opsional, tapi berguna supaya Dzaky dan yang lain tahu apa saja yang berubah di `main`.

## 🤖 Claude · 14 Oct 2026 15:22

Saat `notepad .env` dibuka, isinya seperti ini (salinan dari `.env.example`):

```
# 32 byte acak, base64. Generate:
# python -c "import os,base64;print(base64.b64encode(os.urandom(32)).decode())"
MASTER_SECRET=
# String acak minimal 32 karakter, terpisah dari MASTER_SECRET. Generate:
# python -c "import secrets;print(secrets.token_urlsafe(48))"
JWT_SECRET=
DATABASE_URL=sqlite:///./awan.db
STORAGE_DIR=./storage
SESSION_MINUTES=60
```

Baris yang diawali `#` itu hanya komentar dan boleh dibiarkan. Yang perlu diisi cuma **dua baris yang masih kosong**: `MASTER_SECRET=` dan `JWT_SECRET=`.

Dua perintah `python -c ...` tadi masing-masing mencetak satu teks acak di terminal. Salin teks itu dan tempel **tepat setelah tanda `=`**, tanpa spasi dan tanpa tanda kutip. Hasilnya kira-kira seperti ini:

```
# 32 byte acak, base64. Generate:
# python -c "import os,base64;print(base64.b64encode(os.urandom(32)).decode())"
MASTER_SECRET=q3Zt8mR1vX0aJk5Wn2Yp7Lc9Hs4Ue6Bd1Gf0Ti8Ro2M=
# String acak minimal 32 karakter, terpisah dari MASTER_SECRET. Generate:
# python -c "import secrets;print(secrets.token_urlsafe(48))"
JWT_SECRET=Xk2_pQ9vLm4Rt7Wz1Bn8Yc3Hs6Jd0Fg5Ka2Ue9Vo7Ti4Pw1Mr8Nq3Ls6Dx0Cz5E
DATABASE_URL=sqlite:///./awan.db
STORAGE_DIR=./storage
SESSION_MINUTES=60
```

**Nilai di atas hanya contoh bentuknya, jangan disalin.** Pakai hasil dari terminalmu sendiri. Ciri-cirinya: `MASTER_SECRET` panjangnya 44 karakter dan biasanya diakhiri `=`, sedangkan `JWT_SECRET` panjangnya 64 karakter. Setelah itu simpan dengan `Ctrl+S`, lalu tutup Notepad.

Kalau mau lebih praktis, satu perintah ini membuat `.env` lengkap dengan secret yang sudah terisi (menimpa `.env` yang ada sekarang):

```powershell
python -c "import os,base64,secrets; open('.env','w').write(f'MASTER_SECRET={base64.b64encode(os.urandom(32)).decode()}\nJWT_SECRET={secrets.token_urlsafe(48)}\nDATABASE_URL=sqlite:///./awan.db\nSTORAGE_DIR=./storage\nSESSION_MINUTES=60\n')"
```

Untuk mengecek `.env` sudah benar, jalankan `python scripts\seed.py --password demo12345`. Kalau secret-nya salah atau kosong, akan muncul pesan yang menyebut bagian mana yang salah. Kalau benar, muncul 3 akun yang berhasil dibuat.

## 🤖 Claude · 14 Oct 2026 16:04

Aman. `deactivate` cuma **mematikan venv di terminal itu saja**. Tidak ada yang terhapus atau rusak:

- Folder `.venv` beserta semua library di dalamnya (FastAPI, PyCryptodome, dll.) tetap ada.
- `.env`, `awan.db`, `storage`, dan kode semuanya tidak tersentuh.

Yang berubah hanya: perintah `python` di terminal itu kembali memakai Python bawaan Windows, yang **tidak punya** library proyek ini. Jadi kalau mau menjalankan sesuatu lagi, aktifkan dulu:

```powershell
cd C:\Users\ASUS\Documents\kuliah\sem5\KI\BE
.venv\Scripts\activate
```

Tanda venv sedang aktif: muncul `(.venv)` di depan prompt terminal, misalnya `(.venv) PS C:\...\BE>`.

Kalau lupa mengaktifkan, biasanya muncul error seperti `ModuleNotFoundError: No module named 'fastapi'`. Itu bukan berarti ada yang rusak, cukup aktifkan venv lalu ulangi perintahnya.

Tiap kali membuka terminal baru, venv perlu diaktifkan lagi, karena aktivasi hanya berlaku di terminal tempat perintah itu dijalankan.
